# Discussions

GitHub Discussions is the project's community forum: `https://github.com/ghanendrasahu/production-engineering/discussions`

## Categories and When to Use Them

| Category | Emoji | Purpose | Examples |
|---|---|---|---|
| **Announcements** | 📣 | Release notes, maintainer updates | "v1.1.0 released" |
| **Q&A** | 🙏 | Usage questions, install problems, "which pattern do I use?" | "Should this retry go before or after the DLQ?" |
| **Ideas** | 💡 | Propose features or new examples | "A Kafka Streams example" |
| **Show and tell** | 🙌 | Your projects using the library | "My FastAPI service built from the skill" |
| **Polls** | 🗳️ | Direction votes | Topic localization priorities |
| **General** | 💬 | Everything else | Job postings? No. Off-topic clearly labeled? Yes |

## Ground Rules

- **Search first** — most questions were asked before; use the search box.
- **One topic per thread** — easier to answer, easier to find later.
- **No support via private messages** — keep answers public where possible.
- **Be patient and kind** — maintainer is one person; community is the point.
- **Anonymize before sharing** — strip tenant names, tokens, internal URLs.

## What Belongs Elsewhere

| You want to… | Use |
|---|---|
| Report a bug or wrong claim | Issues → bug_report.md |
| Propose a new topic | Issues → new_skill_proposal.md |
| Report something security-sensitive | [SECURITY.md](../SECURITY.md) — **private**, never public |
| Contribution process questions | [CONTRIBUTING.md](../CONTRIBUTING.md) |
| Personal technical mentorship | Out of scope — try local meetups, paid communities |

## Answering Questions

If your answer resolves someone's question, click **Mark as answer** in Q&A — it builds the reusable FAQ. If you can verify a claim against official docs, post the source link — unsupported answers get gently challenged.
