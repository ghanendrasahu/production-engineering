# Support

Production Engineering Skills is a community knowledge library. Here is how to get the most from it.

## Quick Help

- **Search first**: use GitHub code search scoped to this repository — e.g. `repo:ghanendrasahu/production-engineering idempotency` — before asking.
- **Ask in [Discussions](https://github.com/ghanendrasahu/production-engineering/discussions)** — the fastest channel for usage questions, architecture reviews, and "which pattern should I use?".
- **Browse the topic index**: [docs/topic-index.md](docs/topic-index.md) maps all 111 topics to their documents and file references.

## What to Ask Where

| You want to… | Use |
| --- | --- |
| Report a wrong/outdated fact in a skill doc | [Bug report issue](https://github.com/ghanendrasahu/production-engineering/issues/new?template=bug_report.md) |
| Propose a new topic/skill | [New skill proposal](https://github.com/ghanendrasahu/production-engineering/issues/new?template=new_skill_proposal.md) |
| Improve docs, wording, examples | [Documentation improvement](https://github.com/ghanendrasahu/production-engineering/issues/new?template=documentation_improvement.md) |
| Ask a usage/architecture question | [Discussions](https://github.com/ghanendrasahu/production-engineering/discussions) |
| Report a security problem | See [SECURITY.md](SECURITY.md) — do not file a public issue |
| Share an integration with another agent | [Feature request](https://github.com/ghanendrasahu/production-engineering/issues/new?template=feature_request.md) + Discussions |

## Getting Agent-Specific Help

- **OpenCode**: see [docs/installation.md](docs/installation.md) and `.agents/skills/production-engineering/SKILL.md`.
- **Claude Code** and other agents: see [docs/supported-agents.md](docs/supported-agents.md).

## Response Expectations

This is maintained by one person on a best-effort basis. Expect:

- Discussions and issues: acknowledged within ~7 days, often faster
- Security reports: acknowledged within 7 days, per [SECURITY.md](SECURITY.md)
- No SLA — but well-scoped contributions are reviewed first

## Want to Help Others?

Answering questions in Discussions, improving examples, and reviewing proposals are all high-value contributions. Start with [CONTRIBUTING.md](CONTRIBUTING.md).
